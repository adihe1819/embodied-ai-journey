## 一、我在项目里做了什么

我们的机器人是一台**只有 5 路舵机**（每条腿 2 路四连杆闭环驱动 + 中央 1 路 25:50 齿轮耦合转向、**无脚踝/髋部侧倾关节**）的 3D 双足机器人。为了避免“2D 玩具环境训完用不了”，我直接在完整闭链 CAD 导出的 MuJoCo 模型（`diagnostic_post_shaft_fix_gear_phase_25.xml`，46 广义坐标、18 条等式约束、`0.25 ms` 物理步长）上从零搭建了 GPU 并行强化学习管线并完成了 8 轮迭代：

1. **笔记本 RTX 5070 Ti 上打通 256 并行 MuJoCo Warp GPU 环境**
   - 解决 Windows 中文路径下 MuJoCo XML 加载与 Warp NVRTC 编译报错（纯 ASCII 临时头文件镜像）；
   - 定位并修复 `mjw.put_data()` 中 `nconmax/njmax` 按环境数重复放大的 O(N²) 内存瓶颈，将 256 并行世界吞吐提升至 **~2,680 环境步/秒（约 CPU 的 53.6×）**。
2. **建立严格的真实鞋底碰撞网格验收口径（排除“假抬脚”）**
   - 排查出刚体原点偏高 80 mm、鞋底盒中心倾斜虚假抬高等陷阱，直接从 `model.mesh_graph` 提取实际参与地面碰撞的鞋底网格 **`L0_visual6 / L1_visual6` 凸包顶点**（1731→257、2098→218，最低点误差 `0.00e+00 m`），在 CPU/GPU 环境内实时计算真净空。
   - 统一有效抬脚定义：`真网格最低点 >= 2.0 mm` + `摆动脚受力 < 0.5 N` + `对侧支撑脚受力 > 5.0 N` + `连续保持 >= 60 ms`。
3. **用开环物理实验定位五舵机换重倾角边界，系统解决 4 类典型 RL 失败模式**
   - 通过 9 组确定性开环单脚离地实验（[`reports/02_手动单脚离地验证.md`](reports/02_手动单脚离地验证.md)），实测证实该机构无侧倾关节，必须依靠 **`~20°~24°` 自然侧倾换重**才能干净离地（把倾角硬卡在 `17°` 会物理锁死抬脚、逼出 `65%` 拖地滑行）。
   - 逐步定位并修复了“过重负分诱发 0.7 秒自杀”“前后速度不对称与 `max(0, ...)` 二极管整流漏洞”“硬时钟误杀真抬脚”以及“50 Hz 低通限速困死从零探索”等问题；最终通过**对称速度 + 前向硬拖脚死区门控 + 无硬时钟左右交替记忆 + `N_STEPS=64` + 18→19 维（新增 IMU 可观测 `yaw_rad`）无损热启动**跑出双脚交替真离地直行策略。

## 三、目录结构与复现方式

```text
biped-gait-rl/
├── README.md                      # 本说明
├── robot_loader.py                # MuJoCo 模型加载与真碰撞网格凸包净空计算
├── biped_gait_env.py              # 第 8 轮 CPU Gymnasium 环境（19 维观测 / 5 维动作）
├── biped_gait_gpu_env.py          # 第 8 轮 MuJoCo Warp GPU 并行环境（256 世界）
├── replay_gait_v8.py              # 3D 回放与 --headless 30 秒严格验收脚本
├── train_gait_v8_gpu.py           # GPU 训练 / 续训脚本（仅手动运行）
├── weights/round8_20261126/       # 第 8 轮解包后的 SB3 策略权重（policy.pth 等）
├── reports/                       # 完整 8 轮工程复盘、开环物理实验与上线前校验报告
└── results/                       # 实验 02 / 05 / 06 原始结构化 JSON 数据
```

### 本地复现（需先拉取团队仓库获取 CAD 网格与 XML）

```bash
git clone https://github.com/kdwbll/Biped_Robot.git
# 安装依赖：mujoco gymnasium stable-baselines3 torch numpy
python biped-gait-rl/replay_gait_v8.py --sim-dir ./Biped_Robot/simulation --headless
python biped-gait-rl/replay_gait_v8.py --sim-dir ./Biped_Robot/simulation
```

## 四、当前局限（实事求是）

- **仅限仿真阶段，未上实机**：策略基于假设舵机控制器（`kp=4.0, ki=1.5`）、理想齿轮耦合与固定地面摩擦（`0.8`）训练，尚未经过实物舵机零位/延迟标定与域随机化验证，不能直接下发实体硬件。
- **长程交替待续训优化**：30 秒测试中前 9 秒为稳定双脚交替（`[5, 3]`），9 秒后偏航累积到 `+3.5°~+7.9°` 时右脚略低于 `2.0 mm` 线（30 s 总计 `[19, 3]`），后续计划结合实机标定参数加一轮域随机化与长局（12~15 s）续训。
