## 个人思考

1. 我最先追问的是「三维特征」的每一步具体是什么。把链路拆成深度来源、相机反投影、点云编码和特征融合后，图里的 3D Features 就能对上实际的数据流。
2. 后来对照 [Spatial Forcing](../06-spatial-forcing/README.md)，我发现两篇的几何信息进入策略的时机不同。Any3D-VLA 在推理时接收点云，SF 在训练时用 VGGT 教师特征监督 RGB 表征。我当时问，能不能保留显式点云融合，同时用 VGGT 教 RGB 分支学到更好的几何特征？这是阅读中提出的设想，有待检索已有做法和验证效果。
