## 阅读注释

### 从动作数值到 token

RT-2 的八个字段包括结束指令、末端平移和旋转增量，以及夹爪张开量。连续字段分别分成 256 桶，桶号映射到词表中的符号。训练用对应的动作 token 作为目标，执行时再把它们解回控制量。OpenVLA 的原始动作向量是七维。以官方 LIBERO 评测为例，执行循环读取环境的 `done` 并设置最大步数。[RT-2 §3.2](https://arxiv.org/html/2307.15818v1#S3.SS2) · [OpenVLA §3.2](https://arxiv.org/html/2406.09246v1#S3.SS2) · [LIBERO 评测代码](https://github.com/openvla/openvla/blob/main/experiments/robot/libero/run_libero_eval.py)

### 动作块的两种生成路线

π₀ 用图像、指令和机器人状态作为条件。Action expert 学习 flow matching 的向量场，从噪声出发，经过多次更新得到一整块连续动作。论文任务里的块长为 50 个控制步。块内的机器人步 `t` 与更新这整块动作时使用的生成时间 `τ` 各有自己的含义。[π₀ §IV](https://arxiv.org/html/2410.24164v4#S4)

FAST 把同一动作维度随时间变化的数值当作一段信号。编码依次做归一化、离散余弦变换（DCT）、缩放取整，再按低频优先展开系数交给 BPE 压缩。π₀-FAST 预测压缩后的 token，随后解码并逆变换回动作块。[FAST §V](https://arxiv.org/html/2501.09747v1#S5)

### 子任务、训练反馈和执行接口

| 阅读问题 | 论文中的处理 |
| --- | --- |
| 用户反馈怎么进入动作流程 | Hi Robot 的高层看图和用户指令或反馈，生成短技能指令和可选的回应文本。低层 π₀ 根据短技能指令和观测生成动作。[Hi Robot §4.1](https://arxiv.org/html/2502.19417v2#S4.SS1) |
| 同一个模型如何负责两层输出 | π₀.₅ 先用同一模型预测文字子任务，再以子任务和当前观测为条件，通过 action expert 生成低层动作块。[π₀.₅ §IV-A](https://arxiv.org/html/2504.16054v1#S4.SS1) |
| 执行经验怎样进入下一轮训练 | RECAP 从示范、自主执行和人工纠正中学习。价值函数估计任务的预期回报，优势量衡量行为相对当前预期的改善，再按任务阈值转成条件标签。正负标签样本均可用于训练，执行时指定正优势条件。[RECAP §IV](https://arxiv.org/html/2511.14759v1#S4) |
| 控制器怎样接动作输出 | π₀.₇ 的 `joint` 模式提供关节目标。`ee` 模式提供末端目标位姿，经数值逆运动学转换为关节目标。论文实验中两条路线都由关节控制器执行。[π₀.₇ §V-D](https://arxiv.org/html/2604.15483v2#S5.SS4) · [实验设置](https://arxiv.org/html/2604.15483v2#S8) |

Knowledge Insulation 的动机阅读接着追踪这个训练问题。动作专家在前向计算中能用骨干特征，stop-gradient 限制动作专家损失反向更新骨干，骨干仍可从自己的离散预测任务学习。这篇在对话中先读了动机。[Knowledge Insulation 原文](https://arxiv.org/html/2505.23705v1)

## 个人思考

下列内容按当时的提问和复述整理。

- **10 月 17 日**。我先把位移量想成落在 256 个区间里的连续数值，再问模型预测的八个整数是否对应下一时刻的关节状态。把末端增量、桶号、词表符号和最终关节目标分开后，我开始追问 OpenVLA 少了结束字段时，执行循环从哪里拿到停止信号。
- **10 月 18 日**。我自己指出 π₀ 多了 action expert，接着问自回归、扩散和 flow matching 的关系。读数据时我还把 903M 误读成 903 亿，核对后确认是约 9.03 亿个采样步。这些采样步、动作块里的 50 步、生成动作块时的迭代各有不同的单位。[π₀ §V](https://arxiv.org/html/2410.24164v4#S5)
- **10 月 18 日**。我原先猜相邻 token 相同会让梯度消失。对照 FAST 的讨论后，笔记把问题收窄到动作表示的分辨率和冗余。相邻连续值可能因落入同一桶而丢掉细微差别，重复标签仍能提供交叉熵训练信号。接着我把一段关节运动看成时序信号，要求用机械臂的动作来理解 DCT。
- **10 月 18 日至 19 日**。用“拿起红色杯子”复述 Hi Robot 时，我问既然 π₀ 能执行短指令，为什么还需要一个高层模型。回到复杂任务后，区别变成了“根据场景和反馈选择哪项技能”和“生成动作完成这项技能”。再读 π₀.₅ 时，我继续问同一个模型怎样承担这两项工作。
- **10 月 21 日**。我先想到需要让快速失败的回报低于正常完成，继而问价值函数既然在评价局面，动作好坏究竟靠什么区分。我最初以为重训时只挑正优势轨迹。对照原文，策略以正负优势标签作为条件学习，再在执行时指定正条件。[RECAP §IV-B](https://arxiv.org/html/2511.14759v1#S4.SS2)
- **10 月 22 日**。读到 π₀.₇ 的输入输出后，我问关节控制与末端控制怎样接在一起。两条链路可以追到共同的关节目标和控制器。阅读进度到了输入输出信息流，后续可用一个实际动作样本追踪位姿、逆运动学和关节目标。
