## 个人思考

- 读到引言和图 1 时，我先追问“这里是融合还是监督？”我后来用老师和学生来理解训练与部署的区别。VGGT 在训练时给出同一图像位置的特征目标，训练好的 VLA 负责部署后的图像编码和动作预测。
- 我接着问，部署输入是否还有深度图，图 3 的深度图又是从哪里来的。把训练监督、部署输入和读图探针分开以后，才能跟清同一张 RGB 图在不同分支里经历了什么。
- 准备汇报时，我试着把对齐讲成“在同一块区域，取一层 VLA 的特征，与 VGGT 给出的特征计算损失”。随后我更想追问这个 idea 是怎样形成的，以及“用上 VGGT”之外还有哪些设计判断。继续对照 [Any3D-VLA](../05-any3d-vla/README.md) 时，我想看几何信号在监督和输入融合中的不同作用。
