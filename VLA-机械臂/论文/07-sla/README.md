## 个人思考

- 我先从表 2 的列名问起。Camera、Robot、Layout 具体改变了什么？读每个成功率之前，先把“动了哪个条件”问清楚。
- 读完真机任务和结果后，我问附录里的 Memory Mechanism 在做什么。这个问题把我的注意力从单张图像里的几何信息，带到机械臂做长任务时需要回看哪些已经发生的事情。
- 和 SF 一起准备汇报时，我把“几何监督在哪里用”与“什么时候开始用”放在一起比较。下一次回读方法时，可以进一步查清持续预训练与后训练各用哪些数据、怎样分别验证收益。
